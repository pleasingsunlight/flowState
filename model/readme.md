
# Real-Time Groundwater Level Prediction (DWLR + Rainfall Data)

This repository contains datasets, trained models, and resources for a **real-time groundwater analysis system** using **DWLR (Digital Water Level Recorder) data** and **rainfall datasets** for Jaipur district (extendable to India).  
The project demonstrates how **machine learning (LSTM)** can be applied to predict groundwater levels and support sustainable water management.
